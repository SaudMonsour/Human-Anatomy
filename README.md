# خريطة العضلات والتدريب

أداة تفاعلية للتشريح وتمارين القوة، مبنية باستخدام React وTypeScript وVite، مع واجهتين عربية وإنجليزية.

## الإمكانات
- خريطة أمامية وخلفية للعضلات، مع اختيار منطقة محددة.
- تصميم مخصص للجوال وبحث مدمج ونافذة لاختيار موضع العضلة.
- البحث بين 34 منطقة عضلية و66 تمرينًا.
- إرشادات تنفيذ التمرين والأخطاء الشائعة.
- برنامج أربعة أيام للجزء العلوي والسفلي، ومتابعة الإنجاز الأسبوعي.
- تسجيل الأوزان بالكيلوغرام أو الرطل، ورسوم لحمل التدريب وحجمه.
- سجل قابل للبحث، مع إمكانية التراجع عن الحذف.

## البيانات والخصوصية
تُحفظ التمارين والتفضيلات والإنجاز الأسبوعي داخل تخزين المتصفح المحلي. لا يحتاج الاستخدام إلى حساب أو خادم. حذف بيانات المتصفح يحذف السجل المحفوظ على الجهاز.

## فحوص المشروع
يتحقق فحص البيانات من وجود معلومات تشريحية وتمارين صحيحة ومحتوى عربي لكل عضلة وتمرين. تبقى أوامر المشروع كما هي في المرجع التقني.
